# Inclusive Multimodal UX

Guidance for designing experiences that people can perceive, understand, and control across different input and output modes, devices, and contexts.

## Purpose

This repository brings together cross-platform guidance on modality choice and continuity, sensory and interaction flexibility, semantic structure, and inclusive experience. It supports designers, researchers, product teams, engineers, accessibility specialists, and AI systems working under human authority.

Multimodal design should support meaningful choice and comparable outcomes. It should not assume that every person wants the same combination of modes or that adding channels is always helpful.

## Start here

1. Read [AGENTS.md](AGENTS.md).
2. Define the task, goal, context, and available input/output methods.
3. Use the main guide for general modality questions and the semantic module for detailed structure questions.
4. Route media, cognitive, and immersive specifics to their specialist source.
5. Record evidence, assumptions, limitations, and what should be tested with people.

## Source and consolidation note

The main guide consolidates overlapping frameworks and repeated prompt templates from `Multimodal_UX_Design.md` in [Inclusive and Effective Design](https://github.com/Double-FW/Inclusive_and_Effective_Design). The maturity model and unique prompt material are retained in companion files. The semantic-structure source remains a separate module; shared modality guidance is linked rather than repeated. The source repository has been updated: its original paths now point to the canonical guides here. Use this repository for future multimodal updates and preserve source provenance when revising the material.

## Status

The consolidated guidance and companion modules are available for use and review. They provide design support, not a legal or conformance determination, a validated maturity instrument, or evidence of user outcomes.
